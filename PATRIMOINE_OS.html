Créer une clé API ↗
📋 Guide création clé API Bitget :
1. Bitget → Avatar → Gestion des clés API
2. Créer → Type: Système → Permission: Lecture seule ✓
3. Restriction IP → Désactiver (sinon bloqué par le proxy)
4. Copiez les 3 valeurs ci-dessous immédiatement
⚠ Note technique CORS — Les navigateurs bloquent les requêtes directes vers Bitget. NEXUS passe par un proxy transparent. Si la connexion échoue malgré des clés correctes, installez l'extension CORS Unblock (Chrome / Firefox) et rechargez la page.
🤖 IA (Claude ou DeepSeek…)

L'IA est gérée côté serveur NEXUS — la clé ne transite plus par le navigateur. Choisissez le fournisseur sur le serveur : Claude (ANTHROPIC_API_KEY) ou une API compatible OpenAI sans Claude — DeepSeek, OpenRouter (gratuit), Groq, Ollama local (AI_PROVIDER=openai + AI_BASE_URL + AI_API_KEY). Détails dans DEPLOY.md. Le champ ci-dessous ne sert qu'en usage hors-ligne (sans serveur), avec une clé Claude.
